# MEX TANIM FF POINT TABLE MAKER V9

V9 fixes the tiny text problem on Android/Termux by using Android system bold fonts when available, with a scalable Pillow fallback. Premium 1 team names and all point values are larger and clearer. Premium 1 and Premium 2 designs, sorting, totals and saved data remain unchanged.

Run:
```
pip install -r requirements.txt
python -m py_compile app.py
python app.py
```
Then open http://127.0.0.1:5000
